# alaliadvocates-ai

Crawlable AI-assistant mirror for **Husain Al Ali Advocates & Legal Consultants**, a UAE-licensed law firm in Dubai.

Live site: https://ai.alaliadvocates.com/

This mirror exists so AI assistants (ChatGPT, Claude, Perplexity, Gemini) and search engines can reliably crawl and cite summarized, publicly available information about the firm's practice areas, founder, and contact details, independent of the firm's main hosting infrastructure.

The official, canonical website for the firm is https://alaliadvocates.com/ — this mirror's homepage declares that domain as its canonical URL and defers to it as the authoritative source.

- Homepage: https://ai.alaliadvocates.com/
- llms.txt: https://ai.alaliadvocates.com/llms.txt
- robots.txt: https://ai.alaliadvocates.com/robots.txt (explicitly allows GPTBot, ClaudeBot, PerplexityBot, Google-Extended, Bingbot, and standard search crawlers)
